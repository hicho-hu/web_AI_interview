# 手机 H5 版本

手机与 PC 使用同一域名、路由、账号和 API，直接打开任意链接即可自动适配，无需跳转到独立 H5 地址。手机横屏继续使用 H5；PC 和平板沿用原有页面及其响应式规则。

设备识别在 React 首次渲染前执行，由 `src/utils/device.ts` 根据浏览器设备标识、Client Hints、触摸能力及屏幕尺寸判断，并设置 `html[data-device]`。iPhone、Android 手机及其内置浏览器进入 H5；iPad（含桌面 Safari 标识）、Android 平板和桌面设备使用原版本。宽度只是未知触摸设备的兜底条件，缩小 PC 窗口不会启用 H5。浏览器主动伪装设备标识时，以其提供的信号为准。

H5 专用样式集中在 `src/styles/mobile.css`，只对手机生效，并与打印样式隔离。主要交互包括：

- 首页、记录、开始面试、权益、我的五个底部入口；侧边菜单保留邀请好友、帮助等功能，并锁定背景滚动和管理焦点。
- 首页采用单列卡片、双列统计和完整宽度的开始按钮；记录卡片保留日期、模式、状态及独立删除按钮。
- 创建面试支持全屏岗位选择、横向行业类目、触屏表单、配置与分类额度摘要、靠近屏幕底部的创建操作。
- 面试室隐藏主导航，优先展示题目与回答；语音、视频仍使用现有连续对话、实时字幕、录制与回放能力。
- 报告按单列展示能力维度与回答复盘；权益、邀请、资料及账号设置适配窄屏。
- 输入框字号至少 16px，主要按钮至少 44px；处理刘海屏和底部安全区，使用动态视口高度，并在可检测到软键盘遮挡时隐藏底栏。

## 本地预览与验证

```sh
npm run dev
npm test
npm run build
npm run test:e2e:mobile
```

浏览器开发者工具需选择真实手机设备配置并刷新页面，单纯缩小桌面窗口会保留原版本。`test:e2e:mobile` 使用 Chrome 手机模拟运行 H5 用例和现有连续音视频回归；H5 用例也覆盖 PC 与 iPad Mini。截图输出至 `test-results/h5-*.png`，测试报告和失败追踪位于 `test-results/mobile/`。

真机在同一局域网预览时可运行 `npm run dev -- --host 0.0.0.0`，访问电脑局域网地址的 5173 端口。文字流程可用 HTTP 预览；真机麦克风、摄像头和录制需要 HTTPS。自动化中的 iPhone 使用 Chrome 设备模拟，不代表真实 Safari 或微信内置浏览器验收；生产部署后仍需检查真机权限、软键盘、锁屏及音视频表现。

## 本次验证（2026-11-05）

- `npm run build`、36 项单元测试通过。
- 10 项 H5 浏览器用例通过，覆盖 iPhone / Android 模拟、320px 窄屏、横屏、输入视口收缩、岗位目录、完整文字面试、删除与保留记录、模拟购买、邀请长内容以及 PC / iPad Mini 回归。
- 9 项连续音视频用例在 Android 手机模拟下通过，覆盖打断、补充、暂停、自动与手动结束、保存失败恢复、整场录制及回放。
- 现有 9 项权益购买回归、2 项 OSS 浏览器上传及生产构建冒烟测试通过。

业务接口验证使用演示数据或测试夹具，音视频回归使用浏览器合成媒体设备；未连接真实生产账号或执行真实支付。
