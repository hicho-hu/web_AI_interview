# 工作职能岗位目录

创建面试页的岗位弹框参考[前程无忧搜索页](https://we.51job.com/pc/search)的“工作职能”筛选框，保留“一级职能 → 细分职能 → 岗位”层级、原始编码、名称及排序。

数据来自该页面使用的[公开标准职能字典](https://fecdn.51jobcdn.com/fe/mc/dict/dd_funtype_standard.json)，于 2026-11-15 核对。当前有 26 个一级职能、130 个细分职能、1,255 条岗位归类记录，对岗位编码去重后为 1,058 个岗位。部分岗位会出现在不同职能中；筛选时保留归属关系，全局结果和多选按岗位编码去重。

字典快照保存在 `src/data/job-functions-51job.json`，仅包含公开分类名称、编码和来源信息，随前端一起构建发布。弹框打开时无需访问 51job、GitHub 或其他外部目录服务。搜索支持岗位和两级职能名称，最多选择三个岗位，同时保留手动输入及已有岗位入口。选择岗位会保留已经填写的 JD，不从分类名称生成岗位职责；JD 应使用目标公司的实际要求。

后续更新时重新核对参考页面使用的字典，将 `code/value/items` 转为 `code/name/children`，更新快照的日期及目录数量测试，并验证重复编码的跨分类归属。此次仅修改前端目录，无需调整后端或数据库。
